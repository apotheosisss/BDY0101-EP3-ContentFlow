Guía para el computador de la presentación

EP3 BDY0101 · Caso ContentFlow · Claudio Aro · Guillermo Cerda · Manuel Díaz · Sección 001D
Qué vamos a hacer: dejar el tablero de Power BI funcionando en este laptop, conectado a la base de datos de Azure, y ensayar la demostración en vivo.
Tiempo: unos 20 minutos la primera vez. Hacerlo el día anterior, no en la sala.
Repositorio: https://github.com/apotheosisss/BDY0101-EP3-ContentFlow

Parte A · Instalar lo necesario (una sola vez)

ProgramaCómo instalarloCómo comprobarlo
Power BI DesktopMicrosoft Store → buscar “Power BI Desktop” → Obtener.Aparece en el menú Inicio.
Python 3.12python.org → Downloads → Windows. En la primera pantalla del instalador marcar “Add python.exe to PATH” y luego “Install Now”.En PowerShell: python --version muestra 3.12 o superior.

Si PowerShell ya estaba abierto mientras instalaban, ciérrenlo y ábranlo de nuevo para que reconozca los programas.

Parte B · Preparar el proyecto (una sola vez)

1
Descargar el proyecto en una carpeta simple, por ejemplo C:\ContentFlow.
Con Git, abrir PowerShell y ejecutar: 
git clone https://github.com/apotheosisss/BDY0101-EP3-ContentFlow.git C:\ContentFlow
Sin Git: en la página del repositorio → botón verde Code → Download ZIP → descomprimir y renombrar la carpeta a C:\ContentFlow (que dentro de ella estén directamente README.md, scripts, powerbi, etc.).
2
Copiar el archivo .env que les entregó Claudio (por pendrive o mensaje privado) dentro de C:\ContentFlow, junto a README.md.
• El archivo se llama exactamente .env (sin nada antes del punto). Para verificarlo, en el Explorador: Vista → Mostrar → Extensiones de nombre de archivo. Si aparece como .env.txt, renómbrenlo.
• Contiene la clave de la base de datos: no lo suban a GitHub ni lo compartan.
3
Abrir PowerShell en la carpeta: en el Explorador, entrar a C:\ContentFlow, hacer clic en la barra de direcciones, escribir powershell y presionar Enter.
4
Ejecutar el script de preparación: 
powershell -ExecutionPolicy Bypass -File scripts\preparar_equipo.ps1
Tarda 1 a 3 minutos. Debe mostrar los pasos [1/4] a [4/4], las 5 colecciones con 500 documentos cada una y terminar en verde con “Listo. Abre powerbi\ContentFlow.pbip y pulsa Actualizar.”
5
Abrir el tablero: doble clic en C:\ContentFlow\powerbi\ContentFlow.pbip. Cuando cargue, pulsar Actualizar (en el aviso amarillo o en la cinta Inicio).
Si pregunta por niveles de privacidad o acceso a archivos, elegir Ignorar niveles de privacidad / Conectar.
6
Comprobar los valores en la página Resumen ejecutivo:
TarjetaDebe mostrar
Interacciones / publicación2,00
% Usuarios activos83,8 %
% Sentimiento positivo47,1 %
Logro de campañas0,66 %
Arriba a la derecha“Datos actualizados: (fecha y hora de hoy)”
Si todo coincide, guardar con Ctrl + S. El laptop está listo.

Parte C · Ensayar la demo en vivo

La demo prueba que el tablero se actualiza desde la base de datos real. Usar dos ventanas: PowerShell en C:\ContentFlow y Power BI abierto en la página Resumen ejecutivo.

1
Mostrar el estado inicial: la dona “Distribución de reacciones” muestra 499 y “Me encanta” = 111.
2
Insertar datos nuevos en Cosmos DB (60 reacciones “Me encanta” y 20 comentarios): 
.\.venv\Scripts\python.exe scripts\demo_en_vivo.py insertar
3
Ejecutar el ETL (extrae y transforma de nuevo): 
powershell -ExecutionPolicy Bypass -File scripts\actualizar.ps1
No muestra nada en pantalla; termina en unos 20 segundos (el detalle queda en la carpeta logs).
4
En Power BI pulsar Actualizar: las interacciones suben a 1.079, la dona muestra 559 reacciones, “Me encanta” pasa a 171, sube el % de sentimiento positivo y la categoría Tecnología, y cambia la hora de “Datos actualizados”.
5
Dejar la base como estaba (¡no olvidar!): 
.\.venv\Scripts\python.exe scripts\demo_en_vivo.py revertir
powershell -ExecutionPolicy Bypass -File scripts\actualizar.ps1
y pulsar Actualizar otra vez en Power BI. Los valores vuelven a 2,00 / 83,8 % / 47,1 %.
Consejo: para ver en cualquier momento si quedaron datos de la demo en la base: 
.\.venv\Scripts\python.exe scripts\demo_en_vivo.py estado
Debe decir “de la demo 0” en ambas colecciones.

Parte D · El día de la presentación

  • Conectar el laptop a internet antes de empezar y abrir Power BI con el tablero ya cargado.
  • Ejecutar scripts\actualizar.ps1 y pulsar Actualizar en Power BI, para que “Datos actualizados” muestre la hora de ese momento.
  • Dejar PowerShell abierto en C:\ContentFlow con los comandos de la demo a mano (Parte C).
  • Tener abierto el informe docs\informe\Informe_ContentFlow.pdf (diagramas de arquitectura y modelo).
  • Al terminar: ejecutar demo_en_vivo.py revertir si se hizo la demo.

Parte E · Si algo falla

SíntomaSolución
python no se reconoceReinstalar Python marcando “Add python.exe to PATH”, cerrar y volver a abrir PowerShell.
“la ejecución de scripts está deshabilitada”Escribir el comando completo tal como aparece en esta guía, con -ExecutionPolicy Bypass.
“Falta el archivo .env”El .env no está en C:\ContentFlow o se llama .env.txt (Parte B, paso 2).
“No hay conexión con Cosmos DB”Probablemente la red de la sede bloquea el puerto 10255. Conectarse a la zona Wi-Fi de un celular y repetir. Si no es posible, usar el Plan B.
Power BI: “no se encontró el archivo … .csv”Se movió la carpeta del proyecto. Cerrar Power BI sin guardar, ejecutar otra vez preparar_equipo.ps1 y abrir de nuevo.
Las tarjetas dicen “(En blanco)”Falta pulsar Actualizar en Power BI.
La demo dejó datos extrademo_en_vivo.py revertir, luego actualizar.ps1 y Actualizar en Power BI.
Power BI pide iniciar sesiónNo es necesario: cerrar esa ventana; el tablero funciona sin cuenta.
Plan B · sin conexión a Azure. El repositorio ya trae los datos procesados, así que el tablero se puede mostrar aunque no haya acceso a la base (sin Python ni .env): 
powershell -ExecutionPolicy Bypass -File scripts\preparar_equipo.ps1 -SinConexion
Luego abrir ContentFlow.pbip y pulsar Actualizar. Todo el tablero funciona; lo único que no se puede hacer es la demo en vivo (Parte C). En ese caso, explicar la demo con la sección 10 del informe, donde está documentada la prueba (999 → 1.079 interacciones).
